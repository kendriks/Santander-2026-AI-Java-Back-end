# Bootcamp Java Backend & IA

Bootcamp focado no desenvolvimento **back-end com Java 21**, construção de APIs REST seguras, arquitetura de software e integração com Inteligência Artificial.

## 🚀 Sobre o Bootcamp

Durante o bootcamp, serão abordados:

* Java 21 e fundamentos da linguagem
* Desenvolvimento de APIs REST com Spring Boot
* Segurança com Spring Security
* Princípios de Clean Architecture
* Integração de serviços externos com OpenFeign
* Inteligência Artificial generativa
* Integração com Whisper OpenAI e Gemini
* Desenvolvimento de um assistente virtual inteligente por voz

## 📌 Objetivo

Consolidar conhecimentos de desenvolvimento backend profissional com Java e Spring, aplicando boas práticas de arquitetura, segurança, integração de APIs e recursos de Inteligência Artificial.

## 📚 Atividades

### 🎓 Cursos

Cursos com aulas curtas e objetivas, apresentando os conteúdos de forma prática. Cada curso possui uma avaliação para verificar o aprendizado.

### 👨‍🏫 Mentorias

Encontros ao vivo com especialistas para tirar dúvidas, aprofundar os conhecimentos e discutir aplicações práticas dos conteúdos estudados.

### 💻 Desafio de programação

Desafios práticos de programação para aplicar os conhecimentos adquiridos e desenvolver raciocínio lógico e habilidades técnicas.

### 🚀 Desafio de projeto

Projetos práticos que integram diferentes conhecimentos do bootcamp para solucionar problemas reais e gerar aplicações que podem fazer parte do portfólio.
